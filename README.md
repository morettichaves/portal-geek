# PORTAL GEEK

Projeto conceitual de uma loja geek criado como exercício de **Visual Design — Zion**. A proposta é transformar uma loja em um portal para cultura pop, unindo produtos, pessoas e comunidade em uma experiência visual imersiva.

## Objetivo

Apresentar a marca **PORTAL GEEK** de forma criativa, comercial e memorável, com foco em universos de animes, games, filmes, HQs e colecionáveis. O layout foi pensado para impressionar o dono da loja e funcionar como peça de portfólio.

## Tecnologias

- HTML5 semântico
- CSS3 responsivo e animações nativas
- JavaScript puro
- Google Fonts

## Conceito visual

Interface escura inspirada em portais intergalácticos, tecnologia e ficção científica. A paleta usa azul elétrico, roxo neon, rosa-magenta e verde-limão, com foco nas palavras: **CRIATIVIDADE, UNIVERSO GEEK, COMUNIDADE, CONEXÃO, COLECIONÁVEIS, EXPERIÊNCIA e EXCLUSIVIDADE**.

## Funcionalidades

- Navegação fixa e menu mobile
- Seções de produtos, equipe, comunidade, feedbacks e localização
- Cards com efeitos de hover e animações de entrada
- Botões de produto integráveis ao WhatsApp
- Página de links estilo Linktree em `pages/linktree.html`
- Layout responsivo para celular, tablet e desktop

## Como executar

1. Baixe ou clone este repositório.
2. Abra a pasta no VS Code.
3. Abra `index.html` no navegador ou use a extensão **Live Server**.

> Este projeto é conceitual e usa endereço, equipe, avaliações e produtos fictícios para fins educacionais.
